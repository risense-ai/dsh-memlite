01它能做什么What it does

六件事，全部发生在你自己的机器上。

Six things, all on your own machine.

🧠

自动想起

Auto recall

每次新对话开始，自动找出相关的旧记忆放进对话；只带标题，不占篇幅；需要细节时 AI 再展开全文。

At the start of each new chat, relevant memories are pulled into the conversation automatically. Only titles go in; the AI expands full text when needed.

🌳

来龙去脉

Cause & effect

一条记忆可以挂在前因后面，形成「前因 → 后果」的线索。想起一条，就能看到它从哪来、导致了什么。

A memory can hang under its cause, forming a cause → effect trail. One hit shows where it came from and what followed.

Visual settings

Open settings from the Plugins sidebar and click through the common options. Changes apply immediately — no config files to edit.

🛡️

敏感信息保护

Secret protection

写入前先检查密码、API 密钥、身份证、银行卡等敏感内容；命中就拒绝，并建议只记存放位置。

Before writing, passwords, API keys, ID numbers, bank cards and similar secrets are checked; hits are rejected with a suggestion to store only a location reference.

Moving to another computer? Sync the library to your own private space. Only memory files are committed — your staged work is left alone. A little Git knowledge helps.

02为什么可信Why trust it

记忆是私事。下面六条是默认行为，不需要额外配置。

Memory is personal. These six things are the default — no extra setup.

  • 默认只写本机Local by default 记忆保存在你自己的电脑上，不配置同步就不会上传；默认的搜索方式也不联网。 Memories live on your computer and are not uploaded unless you set up sync. The default search works without network access.
  • 不依赖远程服务No remote service required 不需要云服务、账号或常驻后台；默认纯本地检索，断网也能用。嵌入服务和同步都是可选项。 No cloud service, account or background daemon. Search runs locally and works offline; embeddings and sync are optional.
  • 敏感信息先拦下Secrets blocked first 密码、API 密钥、身份证、银行卡等，写入前检查；命中就拒绝，并建议只记“放在哪里”。 Passwords, API keys, ID numbers, bank cards and similar secrets are checked before writing; hits are rejected with a suggestion to store only where they live.
  • 同步由你掌控Sync stays yours 可选同步到你自己的私有空间；不配置就完全本地。需要一点 Git 基础。 Optional sync to your own private space; skip it and everything stays local. A little Git knowledge helps.
  • 免费开源Free & open source 免费开源，代码可查；没有订阅费，也没有按次计费。 Free and open source, open to inspection. No subscription, no per-use fee.
  • 数据随时能带走Your data stays portable 记忆就是本机上的普通文件，复制即可备份，不绑定某个平台或账号。 Memories are ordinary local files. Copy them to back up or move them; they are not locked to an account or platform.

03多窗口、多进程同时用Multiple windows and processes

默认是单写者：一台机器上由一个 DSH 实例负责写。多开窗口、再跑 CLI 时，可以显式开启本地多进程；写入会排队，不会互相覆盖。

By default there is one writer per library. If you open several DSH windows or also use the CLI, enable local multi-process mode: writes queue up instead of overwriting each other.

默认：单写者

Default: one writer

适合日常使用。读取可以并发；写入走同一把协作锁。只有单个 DSH 实例写入时，不需要额外配置。

Best for everyday use. Reads can run concurrently; writes take the same cooperative lock. No extra setup when only one DSH instance writes.

开启：本地多进程

Enable: local multi-process

在配置的 concurrency 段设置 mode 为 multi-process。多个 DSH 窗口与 CLI 同时写同一目录时，每次提交在锁内重新校验，不会丢新增；同一条记忆的编辑冲突会提示“已被其他窗口修改”。

Set concurrency.mode to multi-process. Multiple DSH windows and the CLI can write the same directory; each commit re-validates under the lock, so new entries are not lost. Editing the same memory elsewhere returns a “modified in another window” conflict.

编辑冲突不静默覆盖

Conflicts are explicit

界面编辑带版本号；另一个窗口先保存后，本次保存会提示冲突并保留草稿。刷新后再决定重试或放弃，不自动覆盖。

UI edits carry a revision. If another window saved first, the save reports a conflict and keeps your draft. Refresh, then retry or discard — nothing is overwritten silently.

跨设备与 NAS

Other machines and NAS

跨设备仍用私有 git 同步；不要用 SMB/云同步盘当共享库。NFS 有显式开关与隔离探针，但尚未完成真实双客户端验收，默认不建议开启。

Use private git sync across machines; do not put the library on SMB or a cloud-sync folder. NFS has an explicit opt-in and a probe, but real two-client validation is not complete, so it is not recommended by default.

状态页看哪里：「状态」视图会显示当前锁后端（flock 或 in-process）、协议版本与数据代次。若显示 in-process，说明原生锁不可用，此时只能保证单写者，不要多开写库。 In the status view: the lock backend (flock or in-process), protocol version and data generation are shown. If it says in-process, native locking is unavailable: only a single writer is safe.

05常见问题FAQ

记错了怎么改？How do I fix a wrong memory?

直接在对话里说「把刚才那条改成……」，让 AI 更新；不用手动翻文件。更新会保留原记录，不会悄悄覆盖。

Just say “change that memory to …” in the chat and let the AI update it. No file editing. Updates keep the original record instead of silently overwriting it.

怎么删？删了还能恢复吗？How do I delete? Can it be undone?

说「删掉这条」即可。删除后不会再被想起；本机文件里保留删除标记，不会发给别人。如果配置了私有同步，删除标记也会同步到你自己的仓库。目前没有一键恢复按钮，误删需要人工处理。

Say “delete that memory”. It will no longer be recalled. A deletion marker stays in the local file and is not sent to anyone else; if you enabled private sync, it syncs to your own repository like any other change. There is no one-click undo yet; accidental deletion needs manual recovery.

换电脑怎么办？What if I change computers?

把本机的记忆文件夹复制到新电脑，或配置私有同步（需要一点 Git 基础）。不配置同步也不影响使用。

Copy the memory folder to the new machine, or set up private sync (a little Git knowledge helps). Skipping sync does not affect normal use.

误拦了敏感信息怎么办？What if a safe note is blocked?

把内容改成“位置提示”，例如“密码在密码管理器里”，再记一次。不建议关闭拦截；确实要关，在配置页里可以找到开关。

Rewrite it as a pointer, e.g. “the password is in the password manager”, and save again. Turning the gate off is not recommended; the switch is in settings if you really need it.

要背 16 个命令吗？Do I need to memorize 16 commands?

不用。日常只有「记：」和自然语言；命令是给开发者的进阶用法，完整列表在 README。

No. Day to day you only need “remember:” and plain language. The commands are advanced tools for developers; the full list is in the README.

会上传我的记忆吗？Are my memories uploaded?

默认不会。只有你主动配置的嵌入服务或私有同步目标会收到数据；不配置就只在本机。

Not by default. Only an embedding service or sync target you configure receives data. Without them, everything stays local.
