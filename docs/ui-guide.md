# dsh-memlite 界面指南（0.5.0）

> 对应实现：`src/client/MemliteMemory.tsx`、`memory-editor.tsx`、`memory-receipt.tsx`、
> `memory-status-view.tsx`、`memory-ui.ts`。截图见 `docs/images/ui-v0.5.0/`（本地 preview fixture）。
>
> 本地预览：`pnpm preview` 后 `python3 -m http.server 8123 -d preview`，打开 `http://127.0.0.1:8123/`。

## 一处入口

- 聊天右侧栏「记忆」页签是唯一主入口；聊天内嵌回复操作栏因宿主没有稳定 slot，本轮未挂载。
- 顶栏四个视图：本次对话 / 全部记忆 / 因果树 / 状态。顶栏状态文字直达状态视图。
- 「＋ 存入」在插件启用时出现；禁用时按钮置灰，不先让用户填一大段再报错。

## 一个动作名

| 动作 | 文案（zh） | 成功回执 |
|---|---|---|
| 新建 | 存入记忆 | 已存入并读回核对 |
| 编辑 | 编辑记忆 / 保存修改 | 已更新并读回核对 |
| 续写 | 基于此续写 | 已存入并读回核对 |
| 改挂 | 改挂因果 / 确认改挂 | 已改挂因果 |
| 忘记 | 忘记 / 确认忘记 | 已忘记 |

红色只用于破坏性操作（忘记、失败、冲突）。阈值与预算用中性徽章，不用错误红。

## 证据分层

- 候选 ≠ 已注入：会话视图逐条显示已注入 / 低于阈值 / 预算截断 / 候选未注入。
- 本地 JSONL ≠ 已加密：状态页只显示「本地·可用」，不声称加密。
- 嵌入已配置 ≠ 本次使用：`host` 档在 DSH 0.2.x 明确不可用并回退 BM25。
- 同步完成 ≠ 远端已验证：状态页区分可用 / 未配置 / 脏 / 未验证；只有 `verified=true` 才显示工作区干净。

## 写入回执

| 状态 | 使用条件 | 禁止表达 |
|---|---|---|
| saved | 写后读回一致 | 已同步 / 已被模型采用 |
| saved-degraded | JSONL 已保存但语义索引未完成 | 写入失败 / 语义检索已包含 |
| rejected | 敏感闸、校验、父条不存在、确认标题不符 | 已保存 |
| conflict | expectedRevision 不匹配 | 覆盖了并发版本 |
| failed | 未知写入异常 | 已保存 |
| unconfirmed | 请求发出后连接中断 | 已保存；不得自动重试 |

冲突时编辑器保留草稿，提供「重新载入当前版本」与「复制我的草稿」。
`unconfirmed` 提示先刷新并按 id 核实，不自动二次写。

## 布局与可访问性

- 侧栏最小 320px；360–520px 单列，详情在面板内下一层；≥720px 列表 280–320px + 详情自适应。
- 正文 14px/1.55，辅助文字 12–13px；计数与分数使用等宽数字；长文 `white-space: pre-wrap`。
- 键盘焦点可见；触控目标 ≥32px；主要按钮 40px 高度由宿主样式决定；弹层可 Escape 关闭（编辑器使用面板内层，取消按钮常驻）。
- 中英文、200% 缩放、320px 宽无横向溢出；亮暗主题全部通过 `--dsw-*` 变量。

## 安全边界

- 不显示密钥、向量、原始提示词、完整路径、remote URL 或任意 `extra`。
- 正文只进 `<pre>` / textarea，不执行记忆中的 HTML 或命令。
- 反馈只记录不自动调权；账本与回执是内存态，重载清空，不称永久审计。
- 没有 pending 审批、撤销删除、永久审计、自动提炼、多 Provider 空间；不在 UI 虚构。

## 已知限制

- **用户级回退读取**：检索在项目级无命中时会回退用户级库；这类命中可在列表/会话中出现，
  但当前详情与写入仍以项目级引擎为准。详情会提示「不在当前项目库中（可能已删除，或来自用户级回退）」，
  不冒充当前库条目。跨库编辑不在 0.5.0 范围。
- **聊天内嵌入口**：宿主没有稳定的回复操作栏/尾部 slot，本轮只保留右侧入口；不修改宿主源码伪造挂载点。
- **跨进程并发**：条件写前会按 JSONL 文件签名重载并比较 revision；极端情况下两个进程同时写入仍可能由
  文件系统最后追加决定，但 UI 不会静默覆盖同一实例内的并发版本。
